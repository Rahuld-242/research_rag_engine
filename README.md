# Research RAG Engine

A research-focused Retrieval-Augmented Generation project for ingesting, indexing, retrieving, and evaluating information from research papers.

## Current capabilities

- PDF discovery and metadata extraction
- Document parsing and chunking
- Chunk metadata generation
- SentenceTransformer embeddings
- Qdrant vector indexing
- JSONL persistence and incremental indexing
- Query embedding and retrieval development in progress

## Planned work

- Top-k semantic retrieval from Qdrant
- Retrieval evaluation
- Context construction
- End-to-end RAG generation
- Multi-query retrieval
- Reranking and hybrid retrieval
- Agentic research workflows
